# 1. RUNTIME & PLATFORM REQUIREMENTS (ÇALIŞMA ORTAMI VE SİSTEM GEREKSİNİMLERİ)
# ------------------------------------------------------------------------------
# İşletim Sistemi (OS):
#   - Windows 10 (64-bit) / Windows 11 (64-bit) (Geliştirme / Test)
#   - Windows Server 2016 / 2019 / 2022 (Üretim / Canlı Ortam)

# .NET Framework:
#   - Microsoft .NET Framework 4.7.2 (Geliştirici Paketi veya Runtime)
#   - C# 10.0 Desteği

# Web Sunucusu (Web Server):
#   - Internet Information Services (IIS) 10.0+ (Canlı Sunucu)
#   - IIS Express 10.0+ (Yerel Geliştirme Ortamı)
#   - Gerekli IIS Modülleri: ASP.NET 4.7, HTTP Redirection, Static Content, Windows/Forms Authentication

# Geliştirme Ortamı (IDE & Build Tools):
#   - Visual Studio 2022 (Community / Professional / Enterprise v17.0+)
#   - Workload: "ASP.NET and web development"
#   - MSBuild 17.0+
#   - NuGet Paket Yöneticisi CLI v6.0+

# ------------------------------------------------------------------------------
# 2. DATABASE REQUIREMENTS (VERİTABANI GEREKSİNİMLERİ)
# ------------------------------------------------------------------------------
# Veritabanı Motoru:
#   - MySQL Server 8.0+ veya MariaDB 10.5+
#   - Depolama Motoru: InnoDB (ACID İşlem Desteği için Zorunlu)
#   - Karakter Seti & Collation: utf8mb4 / utf8mb4_unicode_ci

# Gerekli Veritabanları:
#   - `cabinext`      : Ana operasyonel veritabanı (cabinets, cabinetmovements, locations, locationhierarchies)
#   - `cabinext_logs` : Hata ve denetim kayıtları veritabanı (failed_kiosks)

# Veritabanı Kullanıcı Yetkileri:
#   - SELECT, INSERT, UPDATE, DELETE, CREATE, INDEX, ALTER, DROP

# ------------------------------------------------------------------------------
# 3. NETWORK & EXTERNAL SERVICE REQUIREMENTS (AĞ VE ENTEGRASYON GEREKSİNİMLERİ)
# ------------------------------------------------------------------------------
# Portlar:
#   - Port 80 (HTTP) & Port 443 (HTTPS) - Web Erişimi
#   - Port 3306 (TCP) - MySQL Veritabanı İletişimi

# Dış Servis Bağlantıları:
#   - Cabinext Merkezi Kimlik Doğrulama Servisi (OAuth 2.0 Password Grant)
#   - Güvenlik Protokolü: TLS 1.2 veya TLS 1.3 zorunlu

# ------------------------------------------------------------------------------
# 4. HARDWARE SPECIFICATIONS (DONANIM GEREKSİNİMLERİ)

# Önerilen Donanım (Yoğun Toplu CSV Aktarımları İçin):
